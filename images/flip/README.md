# UNO Flip sticker assets

The files in this directory are generated by `images/build_flip_deck.py`.
Numbers, Reverse, Skip and Wild reuse the repository's original classic card
artwork. Light-side files are exact copies; dark-side files preserve the same
artwork and replace only the color palette and accessibility marker.

The new UNO Flip actions are generated only if missing. A normal regeneration
does not overwrite them, so they can safely be edited by hand. Pass
`--overwrite-new-specials` only when you intentionally want to recreate them.

There are 54 unique cards per side, each available as PNG and lossless WebP,
plus a disabled variant for cards that cannot be played. Reused cards use
the original red-frame treatment; new actions retain their existing artwork.
All cards are 340×512 pixels, so one side is exactly 512 pixels as required
for Telegram static stickers.

Regenerate the deck:

```sh
python -m pip install -r images/requirements-assets.txt
python images/build_flip_deck.py
```

Manual edits to new actions are preserved in all four asset folders. After
editing a PNG, remove only its matching WebP and regenerate to export the edit.

Publish both packs through the Bot API (the owner must first message the bot):

```sh
export TOKEN='123456:...'
export TELEGRAM_USER_ID='123456789'
python images/upload_flip_stickers.py
```

The uploader creates `sticker_ids.json`. The bot loads that manifest on
startup and automatically falls back to textual cards when it is absent.
Use `FLIP_STICKER_MANIFEST` to load it from a different location.
